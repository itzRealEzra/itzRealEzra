## About Me

I'm a developer who enjoys learning by building real things.

I work across **software development, web development, embedded systems, AI, computer vision, automation, and game development**. I like experimenting with different technologies and combining them when a project calls for it.

Most of my ideas start with:

> **"Can I just build this myself?"**

And yes, I'm lazy — but mostly in the engineering sense:

> **"I'm too lazy to repeat this 500 times, so I'll spend three days automating it."**

I prefer practical experimentation, understanding how systems work, and improving things step by step.

## How I Build

```text
Idea
 ↓
Prototype
 ↓
Break It
 ↓
Understand It
 ↓
Fix It
 ↓
Improve It
```

I don't always start with the perfect solution.

I start with something that works, learn from it, and make the next version better.

---

## Development Philosophy

> **Build first. Understand deeply. Improve continuously.**

I'm interested in technology that is **useful, interactive, practical, or simply fun to build**.

And whenever I catch myself doing the same thing twice:

```text
Can I automate this?
        ↓
      Yes.
        ↓
   Build it.
```
