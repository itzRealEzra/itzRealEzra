I build software, experiment with hardware, and explore the space where **code, interfaces, intelligent systems, and physical devices** meet.

My work spans from **web interfaces and software applications** to **Arduino/ESP systems, DMX lighting, AI projects, and game development**.

I enjoy building from the ground up — understanding how things work, breaking them, rebuilding them better, and turning ideas into actual projects.

# Selected Work

## ESP32 DMX Sound Reactive Lighting

An ESP32-based lighting system combining **DMX512 control, microphone input, and sound-reactive effects**.

The project explores the connection between hardware, real-time data, and lighting systems.

**Stack**

`ESP32` · `C++` · `MAX485` · `MAX9814` · `DMX512` · `OTA`

**Repository**

https://github.com/itzRealEzra/Esp32-DMX-Sound-Reactive-Lighting

---

## Ashborne — The PC Partner

An experimental AI project focused on building a **personal PC companion**.

The current direction focuses on conversational interaction and establishing the AI foundation before expanding into deeper PC functionality and automation.

**Stack**

`Python` · `AI APIs` · `GUI Development` · `Automation`

---

## Artherix Fantasy

A fantasy / cultivation-inspired game project exploring **world building, progression systems, classes, combat, exploration, and interactive RPG systems**.

The project combines programming, game systems, interface design, and visual direction into one large experimental environment.

**Focus**

`Game Systems` · `UI` · `World Design` · `Combat` · `Progression` · `Interactive Systems`

---

## Phone Camera Detection

An experimental project exploring the use of a **phone camera as a PC input device**, with a focus on human detection and hand/skeleton interaction.

**Focus**

`Computer Vision` · `Camera Streaming` · `Pose Detection` · `PC Interaction`
