### ⚡ ESP32 DMX Sound Reactive Lighting

An ESP32-based lighting controller combining **DMX512**, microphone input, and sound-reactive lighting effects.

**Hardware / Technologies**

* ESP32
* MAX485
* MAX9814
* DMX512
* Moving Head
* RGB / PAR lighting
* OTA updates

🔗 **Repository:**
https://github.com/itzRealEzra/Esp32-DMX-Sound-Reactive-Lighting

### 🤖 Ashborne — The PC Partner

An experimental AI PC assistant designed to become a conversational companion for interacting with and eventually controlling a PC.

Current direction:

```text
User
  │
  ▼

├─────────────────────┤
│ Conversation        │
│ Context             │
│ Commands            │
```

The project is currently focused on the **chat/AI foundation**, with tools and deeper PC automation planned for later development.
